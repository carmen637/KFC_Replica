Este proyecto consiste en la replicación del diseño del Home de KFC utilizando únicamente HTML y CSS.  
El objetivo principal fue practicar maquetación web, organización visual y uso de estilos para recrear una página comercial real con una estructura moderna y adaptable.


## Objetivos del proyecto
- Reproducir la estructura visual del sitio oficial de KFC.  
- Practicar el uso de **Flexbox**, **Grid** y **posicionamiento CSS**.  
- Mejorar el dominio del **diseño responsivo** y las buenas prácticas en HTML semántico.  
- Analizar cómo una marca organiza su contenido e identidad visual en la web.


## Tecnologías utilizadas
- HTML, CSS
